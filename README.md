# Developer Portfolio

A static, responsive portfolio using the TWZ Holdings brand palette.

## Brand colors
- Midnight Blue: `#191970`
- Brushed Silver: `#C1C4C7`
- Desert White: `#FDFAF1`

## Run locally
Open `index.html` directly, or serve the directory with any static HTTP server.

## Customize
The portfolio content is currently illustrative and centralized in `index.html`. Replace the sample contact email, project details, and dates with confirmed information before publishing. Styling and responsive behavior live in `styles.css`.

No framework, build step, or JavaScript dependency is required.
