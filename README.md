# Developer Portfolio

A static, responsive portfolio built with **Vue 3** and **Vite**, using the TWZ Holdings brand palette.

## Brand colors
- Midnight Blue: `#191970`
- Brushed Silver: `#C1C4C7`
- Desert White: `#FDFAF1`

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy to Vercel
Import this repository into Vercel. Vercel should detect Vite automatically:
- Build command: `npm run build`
- Output directory: `dist`

## Customize
Portfolio content is centralized in `src/App.vue`. Replace the sample contact email and illustrative project details before publishing. Styling lives in `src/style.css`.
